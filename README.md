**Frontend Engineer and automation-focused developer building practical web products, data pipelines, and self-hosted infrastructure.**

I work mostly with React, Next.js, TypeScript, Node.js, Python, Docker, and Linux. My current focus is turning operational problems into reliable systems: dashboards, APIs, automations, scraping pipelines, product analytics, and homelab infrastructure that is easy to reproduce and maintain.

- Build modern frontend applications with React, Next.js, TypeScript, accessibility, SEO, and performance in mind.

- Maintain self-hosted infrastructure using Docker, Linux, Tailscale, Cloudflare, AdGuard Home, Unbound, and automation workflows.

## Engineering Values

- Prefer simple, reproducible, and well-documented systems.
- Keep secrets out of code and design with least privilege in mind.
- Measure before optimizing, especially in databases, APIs, and frontend performance.
- Build automation that reduces repeated work without hiding operational risk.
- Leave clear documentation so future maintenance is easier than the first implementation.
