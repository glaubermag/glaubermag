## Selected work

### [VouDeOfertas](https://voudeofertas.com.br) · [Case study](https://glaubermag.dev.br/projects/voudeofertas)
A multi-marketplace price tracking platform that combines resilient data collection with real price history, helping shoppers distinguish genuine deals from artificial discounts.

**Engineering:** Next.js, React, TypeScript, Node.js, MySQL, Redis, BullMQ, Docker.

A live ranking display for brewery venues, built to run continuously on Android TV boxes and recover from network outages and point-of-sale restarts.

**Engineering:** Angular PWA, Flask, PostgreSQL, Python, incremental synchronization.

Automated price tracking, scheduled reports, webhooks, and notifications in a containerized Node.js service.

**Engineering:** Node.js, MySQL, node-cron, Winston, Docker.
